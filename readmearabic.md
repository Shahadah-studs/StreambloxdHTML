# StreambloxdHTML 🎬
منصة لتخزين ومشاركة مقاطع الفيديو تم بناؤها باستخدام HTML خالص لمجتمع Bloxd. قم بتخزين مقاطع فيديو لعب Bloxd الخاصة بك واكتشف ما يشاركه الآخرون!
**العرض المباشر:** [https://streambloxd-html.vercel.app](https://streambloxd-html.vercel.app)
---
## 📖 نظرة عامة
StreambloxdHTML هي منصة خفيفة الوزن تعتمد على الويب، مصممة لعشاق Bloxd لرفع وتخزين ومشاركة فيديوهات الألعاب الخاصة بهم. تستخدم المنصة نظام مفاتيح فريد يعتمد على الرابط (URL) يتيح للمستخدمين الوصول إلى مجموعات الفيديو عبر روابط بسيطة وقابلة للمشاركة.
### الميزات الرئيسية
- **تخزين سهل للفيديوهات** - ارفع وخزن مقاطع فيديو لعب Bloxd الخاصة بك
- **مشاركة بسيطة** - شارك الفيديوهات باستخدام مفتاح فريد في الرابط
- **وصول يعتمد على الرابط** - قم بتغيير المفتاح بعد `.app/` لعرض مجموعات فيديو مختلفة
- **مدفوع بالمجتمع** - اكتشف وشاهد فيديوهات لاعبين آخرين
- **خفيف الوزن** - مبني بالكامل باستخدام HTML لسرعة التحميل

## 🌟 البدء في التطوير
### استنساخ المستودع (Clone)
```bash
git clone https://github.com/Shahadah-studs/StreambloxdHTML.git
cd StreambloxdHTML
```
### التطوير المحلي
ببساطة افتح `index.html` في متصفحك للتشغيل محلياً:
```bash
# باستخدام Python 3
python -m http.server 8000
# باستخدام Python 2
python -m SimpleHTTPServer 8000
# باستخدام Node.js (إذا كان لديك http-server مثبتاً)
http-server
```
ثم انتقل إلى `http://localhost:8000` في متصفحك.
