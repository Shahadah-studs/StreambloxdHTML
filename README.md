# StreambloxdHTML 🎬

A video storage and sharing platform built with pure HTML for the Bloxd community. Store your Bloxd gameplay videos and discover what others are sharing!

**Live Demo:** [https://streambloxd-html.vercel.app](https://streambloxd-html.vercel.app)

---

## 📖 Overview

StreambloxdHTML is a lightweight, web-based platform designed for Bloxd enthusiasts to upload, store, and share their gaming videos. The platform uses a unique URL-based key system that allows users to access video collections with simple, shareable links.

### Key Features

- **Easy Video Storage** - Upload and store your Bloxd gameplay videos
- **Simple Sharing** - Share videos with a unique key in the URL
- **URL-Based Access** - Change the key after `.app/` to view different video collections
- **Community-Driven** - Discover and watch videos from other players
- **Lightweight** - Built entirely with HTML for fast loading

---

## 🚀 Getting Started

### Viewing Videos

1. Visit [https://streambloxd-html.vercel.app](https://streambloxd-html.vercel.app)
2. Replace the key after `.app/` in the URL with your desired collection key
3. Browse and watch videos from that collection

**Example:**
```
https://streambloxd-html.vercel.app/key-123
https://streambloxd-html.vercel.app/player-xyz
```

### Uploading Videos

1. Access the upload section on the main page
2. Select your video file
3. Receive a unique key for your collection
4. Share the link with others!

## 🔗 URL Structure

The application uses a simple key-based URL structure:

```
https://streambloxd-html.vercel.app/{key}
```

Replace `{key}` with:
- Your user ID
- Your custom key
- A collection name
- Any unique identifier

## 🌟 Getting Started with Development

### Clone the Repository

```bash
git clone https://github.com/Shahadah-studs/StreambloxdHTML.git
cd StreambloxdHTML
```

### Local Development

Simply open `index.html` in your browser to run locally:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have http-server installed)
http-server
```

Then navigate to `http://localhost:8000` in your browser.
